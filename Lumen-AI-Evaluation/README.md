# Lumen AI Evaluation and Model Comparison

An experimental project evaluating AI-generated customer service responses.

## Project Overview

This project examines AI response quality using 20 evaluation examples and five criteria.

## Evaluation Criteria

1. Accuracy
2. Human Escalation
3. Complaint Handling
4. Booking Response Quality
5. Channel Consistency

## Project Structure

- `data/` - Evaluation prompts and generated responses
- `notebooks/` - Kaggle experiment notebook
- `results/` - Evaluation results and model comparisons
